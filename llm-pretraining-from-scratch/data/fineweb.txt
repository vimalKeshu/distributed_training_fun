## Deduplicating the data
- Attempt to remove redundant/repeated data from datasets.
- Possible that different URLs point same site or data. 
- Reducing redundant/repated data help to reduce LLM memorization problem. probably, lead LLM in better generalization.
- By removing duplicate data, model can reach accuracy level with fewer no. of training iterations.
- there are various techniques like hashing the data, finding similarity score among documents etc..
- it's not necessary, deduplication always improve model performance !
- It also depends that based on understanding of the data, new filters can be coined and/or old filters can be dropped. 
  either new one is working and old is not working should come from training small model.

# FineWeb-Edu
- available in two sizes/filtering-level: 
    -> 1.3 trillion (very high educational content) and 
    -> 5.4 trillion (high educational content) tokens (all tokens are measured with GPT2 tokenizer)
- To get high quality dataset, one can use existing open model to annotate the data. 
   This is how FineWeb-Edu data created, by annotating it using llama model.
- Sometime, for annotation running large mdoel costly; in such case, classifier model can be trained using large model and it should be used in annotation process.
- the effectiveness of using classifiers trained on LLM annotations for large-scale data filtering is very good.
